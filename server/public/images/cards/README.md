# Card Images

Place your card images in this folder.

## Naming Convention

Use the card ID as the filename:
- `BLUE-EYES-001.jpg`
- `DARK-MAGICIAN-002.png`
- `SPELL-CARD-123.webp`

## Supported Formats

- `.jpg`, `.jpeg`
- `.png`
- `.webp`
- `.gif`

## Image URL in Admin App

When adding/editing cards, set the Image URL field to:
```
/images/cards/CARD-ID.jpg
```

Example: If your card ID is `BLUE-EYES-001` and you have `BLUE-EYES-001.jpg` in this folder, use:
```
/images/cards/BLUE-EYES-001.jpg
```

## Recommended Image Size

- Width: 300-500px
- Height: 450-750px (maintain 2:3 aspect ratio)
- File size: Under 500KB for better performance
