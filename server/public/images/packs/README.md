# Pack Images

Place your pack images in this folder.

## Naming Convention

Use descriptive names:
- `starter-pack.jpg`
- `champion-pack.png`
- `legendary-pack.webp`

## Supported Formats

- `.jpg`, `.jpeg`
- `.png`
- `.webp`
- `.gif`

## Image URL in Admin App

When adding/editing packs, set the Image URL field to:
```
/images/packs/pack-name.jpg
```

Example: If you have `starter-pack.jpg` in this folder, use:
```
/images/packs/starter-pack.jpg
```

## Recommended Image Size

- Width: 300-500px
- Height: 300-500px (can be square or similar to card ratio)
- File size: Under 500KB for better performance
